恩特林格数​

恩特林格数（Entringer number，OEIS A008281）E(n,k)E(n,k)E(n,k) 是满足下述条件的 000 到 nnn 共 n+1n+1n+1 个数的置换数目：

  • 首元素是 kkk；
  • 首元素的下一个元素比首元素小，再下一个元素比前一个元素大，再下一个元素比前一个元素小……后面相邻元素的大小关系均满足这样的规则。

恩特林格数的初值有：

E(0,0)=1E(0,0)=1E(0,0)=1 E(n,0)=0E(n,0)=0E(n,0)=0

有递推关系：

E(n,k)=E(n,k−1)+E(n−1,n−k)E(n,k)=E(n,k-1)+E(n-1,n-k)E(n,k)=E(n,k−1)+E(n−1,n−k)

交替置换与 zigzag 数​

（注意和「错位排列」进行概念上的区分。）

对于大于 111 的 nnn，每个 zigzag 置换翻转过来仍旧为 zigzag 置换，可以两两配对，所以必然为偶数。

这里再给出一种配对的方法：将 zigzag 置换分为交替置换（alternating permutation）和反交替置换（reverse alternating permutation）。

交替置换的首元素大于第二个元素，大小关系为：

c1>c2<c3>⋯c_1>c_2<c_3>\cdotsc1​>c2​<c3​>⋯

反交替置换的首元素小于第二个元素，大小关系为：

c1<c2>c3<⋯c_1<c_2>c_3<\cdotsc1​<c2​>c3​<⋯

如果将 111 和 nnn 位置互换，222 和 n−1n-1n−1 位置互换，以此类推，即可将交替置换与反交替置换两个集合互换。因此，交替置换与反交替置换的个数相等，恰好为 zigzag 置换的一半。

对于大于 111 的 nnn，记：

An=Zn2A_n=\frac{Z_n}{2}An​=2Zn​​

定义初值：

A0=A1=1A_0=A_1=1A0​=A1​=1

这里的 AnA_nAn​ 称为 zigzag 数（Euler zigzag number，OEIS A000111），从 n=0n=0n=0 开始有：

1,1,1,2,5,16,61,272,⋯1, 1, 1, 2, 5, 16, 61, 272, \cdots1,1,1,2,5,16,61,272,⋯

接下来试着求解 AnA_nAn​。

从 111 到 nnn 之中，选取 kkk 个数构成子集，有 (nk)\dbinom{n}{k}(kn​) 种选法。

在这个 kkk 元子集中，选反交替置换 uuu，有 AkA_kAk​ 种选法；用全集减掉这个 kkk 元子集，剩余的 n−kn-kn−k 元子集中，选反交替置换 vvv，有 An−kA_{n-k}An−k​ 种选法。

考虑 n+1n+1n+1 元排列 www，将 uuu 倒置作为开头，接上 n+1n+1n+1，再接上 vvv。那么，www 一定是 zigzag 置换，并且任意一个 n+1n+1n+1 元 zigzag 置换，都可以在 n+1n+1n+1 处截断得到对应的反交替置换 uuu 和 vvv，并且不同的 n+1n+1n+1 元 zigzag 置换对应的 uuu 和 vvv 不同。

因此有递推关系：

2An+1=∑k=0n(nk)AkAn−k2A_{n+1}=\sum_{k=0}^n \dbinom{n}{k} A_k A_{n-k}2An+1​=k=0∑n​(kn​)Ak​An−k​ 2(n+1)An+1(n+1)!=∑k=0nAkk!An−k(n−k)!2(n+1)\frac{A_{n+1}}{(n+1)!}=\sum_{k=0}^n \frac{A_k}{k!}\frac{A_{n-k}}{(n-k)!}2(n+1)(n+1)!An+1​​=k=0∑n​k!Ak​​(n−k)!An−k​​

当 nnn 为 000 时并不满足这个递推式，初值 A0A_0A0​ 和 A1A_1A1​ 都是 111。

可见，这是一个指数型生成函数的卷积。假设 AnA_nAn​ 的指数型生成函数为 yyy，就有微分方程：

2dydx=y2+12\frac{\mathrm{d}y}{\mathrm{d}x}=y^2+12dxdy​=y2+1

等式右面加 111 是为了处理 nnn 为 000 时的特殊情况。该方程的通解为：

y=tan⁡(12x+C)y=\tan\left(\frac{1}{2}x+C\right)y=tan(21​x+C)

代入第 000 项为 111 之后，可以得到特解：

y=tan⁡x+sec⁡xy=\tan x+\sec xy=tanx+secx

正切函数是奇函数，正割函数是偶函数，两者之和构成 zigzag 数的生成函数。

恩特林格数与 zigzag 数的关系​

根据恩特林格数的定义，恩特林格数 E(n,k)E(n,k)E(n,k) 是首元素为 kkk 的 000 到 nnn 的交替置换个数。因此恩特林格数与 zigzag 数事实上有关系：

An=E(n,n)A_n=E(n,n)An​=E(n,n)

将 AnA_nAn​ 称为「zigzag 数」也有原因：记 EnE_nEn​ 是欧拉数（Euler number），BnB_nBn​ 是伯努利数。

当 nnn 为偶数时，偶数项下标的 zigzag 数也称「正割数」SnS_nSn​ 或者「zig 数」。有关系：

An=(−1)n/2EnA_n=(-1)^{n/2}E_nAn​=(−1)n/2En​

前几项为（OEIS A000364）：

1,1,5,61,1385,⋯1, 1, 5, 61, 1385, \cdots1,1,5,61,1385,⋯

当 nnn 为奇数时，奇数项下标的 zigzag 数也称「正切数」TnT_nTn​ 或者「zag 数」。有关系：

An=(−1)(n−1)/22n+1(2n+1−1)Bn+1n+1A_n=\frac{(-1)^{(n-1)/2}2^{n+1}(2^{n+1}-1)B_{n+1}}{n+1}An​=n+1(−1)(n−1)/22n+1(2n+1−1)Bn+1​​
