贝尔数

贝尔数 BnB_nBn​ 以埃里克·坦普尔·贝尔命名，是组合数学中的一组整数数列，开首是（OEIS A000110）：

B0=1,B1=1,B2=2,B3=5,B4=15,B5=52,B6=203,…B_0 = 1,B_1 = 1,B_2=2,B_3=5,B_4=15,B_5=52,B_6=203,\dotsB0​=1,B1​=1,B2​=2,B3​=5,B4​=15,B5​=52,B6​=203,…

BnB_nBn​ 是基数为 nnn 的集合的划分方法的数目。集合 SSS 的一个划分是定义为 SSS 的两两不相交的非空子集的族，它们的并是 SSS。例如 B3=5B_3 = 5B3​=5 因为 3 个元素的集合 a,b,c{a, b, c}a,b,c 有 5 种不同的划分方法：

{{a},{b},{c}}{{a},{b,c}}{{b},{a,c}}{{c},{a,b}}{{a,b,c}}\begin{aligned} &\{ \{a\},\{b\},\{c\}\} \\ &\{ \{a\},\{b,c\}\} \\ &\{ \{b\},\{a,c\}\} \\ &\{ \{c\},\{a,b\}\} \\ &\{ \{a,b,c\}\} \\ \end{aligned}​{{a},{b},{c}}{{a},{b,c}}{{b},{a,c}}{{c},{a,b}}{{a,b,c}}​

B0B_0B0​ 是 1 因为空集正好有 1 种划分方法。

递推公式​

贝尔数适合递推公式：

Bn+1=∑k=0n(nk)BkB_{n+1}=\sum_{k=0}^n\binom{n}{k}B_{k}Bn+1​=k=0∑n​(kn​)Bk​

证明：

Bn+1B_{n+1}Bn+1​ 是含有 n+1n+1n+1 个元素集合的划分个数，设 BnB_nBn​ 的集合为 {b1,b2,b3,…,bn}\{b_1,b_2,b_3,\dots,b_n\}{b1​,b2​,b3​,…,bn​}，Bn+1B_{n+1}Bn+1​ 的集合为 {b1,b2,b3,…,bn,bn+1}\{b_1,b_2,b_3,\dots,b_n,b_{n+1}\}{b1​,b2​,b3​,…,bn​,bn+1​}，那么可以认为 Bn+1B_{n+1}Bn+1​ 是有 BnB_{n}Bn​ 增添了一个 bn+1b_{n+1}bn+1​ 而产生的，考虑元素 bn+1b_{n+1}bn+1​。

  • 假如它被单独分到一类，那么还剩下 nnn 个元素，这种情况下划分数为 (nn)Bn\dbinom{n}{n}B_{n}(nn​)Bn​;

  • 假如它和某 1 个元素分到一类，那么还剩下 n−1n-1n−1 个元素，这种情况下划分数为 (nn−1)Bn−1\dbinom{n}{n-1}B_{n-1}(n−1n​)Bn−1​；

  • 假如它和某 2 个元素分到一类，那么还剩下 n−2n-2n−2 个元素，这种情况下划分数为 (nn−2)Bn−2\dbinom{n}{n-2}B_{n-2}(n−2n​)Bn−2​；

  • ……

以此类推就得到了上面的公式。

每个贝尔数都是相应的 第二类斯特林数的和。 因为第二类斯特林数是把基数为 nnn 的集合划分为正好 kkk 个非空集的方法数目。

Bn=∑k=0n{nk}B_{n} = \sum_{k=0}^n{n\brace k}Bn​=k=0∑n​{kn​}

贝尔三角形​

用以下方法构造一个三角矩阵（形式类似杨辉三角形）：

  • a0,0=1a_{0,0} = 1a0,0​=1；
  • 对于 n≥1n \ge 1n≥1，第 nnn 行首项等于上一行的末项，即 an,0=an−1,n−1a_{n,0}=a_{n-1,n-1}an,0​=an−1,n−1​；
  • 对于 m,n≥1m,n \ge 1m,n≥1，第 nnn 行第 mmm 项等于它左边和左上角两个数之和，即 an,m=an,m−1+an−1,m−1a_{n,m}=a_{n,m-1}+a_{n-1,m-1}an,m​=an,m−1​+an−1,m−1​。

constexpr int MAXN = 2000 + 5;
int bell[MAXN][MAXN];

void f(int n) {
  bell[0][0] = 1;
  for (int i = 1; i <= n; i++) {
    bell[i][0] = bell[i - 1][i - 1];
    for (int j = 1; j <= i; j++)
      bell[i][j] = bell[i - 1][j - 1] + bell[i][j - 1];
  }
}

指数生成函数​

考虑贝尔数的指数生成函数及其导函数：

B^(x)=∑n=0+∞Bnn!xn=1+∑n=0+∞Bn+1(n+1)!xn+1B^′(x)=∑n=0+∞Bn+1n!xn\begin{aligned} \hat B(x) &= \sum_{n = 0}^{+\infty}\frac{B_n}{n!}x^n \\ &= 1 + \sum_{n = 0}^{+\infty}\frac{B_{n+1}}{(n + 1)!}x^{n + 1} \\ \hat B'(x) &= \sum_{n = 0}^{+\infty}\frac{B_{n+1}}{n!}x^{n} \end{aligned}B^(x)B^′(x)​=n=0∑+∞​n!Bn​​xn=1+n=0∑+∞​(n+1)!Bn+1​​xn+1=n=0∑+∞​n!Bn+1​​xn​

根据贝尔数的递推公式可以得到：

Bn+1n!=∑k=0n1(n−k)!Bkk!\frac{B_{n+1}}{n!} = \sum_{k = 0}^{n}\frac{1}{(n-k)!}\frac{B_{k}}{k!}n!Bn+1​​=k=0∑n​(n−k)!1​k!Bk​​

这是一个卷积的式子，因此有：

B^′(x)=exB^(x)\hat B'(x) = \mathrm{e}^x \hat B(x)B^′(x)=exB^(x)

这是一个微分方程，解得：

B^(x)=exp⁡(ex+C)\hat B(x) = \exp\left(\mathrm{e}^x + C\right)B^(x)=exp(ex+C)

最后当 x=0x = 0x=0 时 B^(x)=1\hat B(x) = 1B^(x)=1，带入后解得 C=−1C = -1C=−1，得到贝尔数指数生成函数的封闭形式：

B^(x)=exp⁡(ex−1)\hat B(x) = \exp\left(\mathrm{e}^x - 1\right)B^(x)=exp(ex−1)

预处理出 ex−1\mathrm{e}^x - 1ex−1 的前 nnn 项后做一次多项式 exp 即可得出贝尔数前 nnn 项，时间复杂度瓶颈在多项式 exp，可做到 O(nlog⁡n)O(n \log n)O(nlogn) 的时间复杂度。
