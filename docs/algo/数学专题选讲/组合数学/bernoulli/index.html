伯努利数

伯努利数 BnB_nBn​ 是一个与数论有密切关联的有理数序列。前几项被发现的伯努利数分别为：

B0=1,B1=−12,B2=16,B3=0,B4=−130,…B_0=1,B_1=-\frac{1}{2},B_2=\frac{1}{6},B_3=0,B_4=-\frac{1}{30},\dotsB0​=1,B1​=−21​,B2​=61​,B3​=0,B4​=−301​,…

等幂求和​

伯努利数是由雅各布·伯努利的名字命名的，他在研究 mmm 次幂和的公式时发现了奇妙的关系。我们记

Sm(n)=∑k=0n−1km=0m+1m+⋯+(n−1)mS_{m}(n)=\sum_{k=0}^{n-1}k^m=0^m+1^m+\dots+(n-1)^mSm​(n)=k=0∑n−1​km=0m+1m+⋯+(n−1)m

伯努利观察了如下一列公式，勾画出一种模式：

S0(n)=nS1(n)=12n2−12nS2(n)=13n3−12n2+16nS3(n)=14n4−12n3+14n2S4(n)=15n5−12n4+13n3−130n\begin{aligned} S_0(n)&=n\\ S_1(n)&=\frac{1}{2}n^2-\frac{1}{2}n\\ S_2(n)&=\frac{1}{3}n^3-\frac{1}{2}n^2+\frac{1}{6}n\\ S_3(n)&=\frac{1}{4}n^4-\frac{1}{2}n^3+\frac{1}{4}n^2\\ S_4(n)&=\frac{1}{5}n^5-\frac{1}{2}n^4+\frac{1}{3}n^3-\frac{1}{30}n \end{aligned}S0​(n)S1​(n)S2​(n)S3​(n)S4​(n)​=n=21​n2−21​n=31​n3−21​n2+61​n=41​n4−21​n3+41​n2=51​n5−21​n4+31​n3−301​n​

可以发现，在 Sm(n)S_m(n)Sm​(n) 中 nm+1n^{m+1}nm+1 的系数总是 1m+1\frac{1}{m+1}m+11​，nmn^mnm 的系数总是 −12-\frac{1}{2}−21​，nm−1n^{m-1}nm−1 的系数总是 m12\frac{m}{12}12m​，nm−3n^{m-3}nm−3 的系数是 −m(m−1)(m−2)720-\frac{m(m-1)(m-2)}{720}−720m(m−1)(m−2)​，nm−4n^{m-4}nm−4 的系数总是零等。

而 nm−kn^{m-k}nm−k 的系数总是某个常数乘以 mk‾m^{\underline{k}}mk​，mk‾m^{\underline{k}}mk​ 表示下降阶乘幂，即 m!(m−k)!\frac{m!}{(m-k)!}(m−k)!m!​。

递推公式​

Sm(n)=1m+1(B0nm+1+(m+11)B1nm+⋯+(m+1m)Bmn)=1m+1∑k=0m(m+1k)Bknm+1−k\begin{aligned} S_m{(n)}&=\frac{1}{m+1}(B_0n^{m+1}+\binom{m+1}{1}B_1 n^m+\dots+\binom{m+1}{m}B_m n) \\ &=\frac{1}{m+1}\sum_{k=0}^{m}\binom{m+1}{k}B_kn^{m+1-k} \end{aligned}Sm​(n)​=m+11​(B0​nm+1+(1m+1​)B1​nm+⋯+(mm+1​)Bm​n)=m+11​k=0∑m​(km+1​)Bk​nm+1−k​

伯努利数由隐含的递推关系定义：

∑j=0m(m+1j)Bj=0,(m>0)B0=1\begin{aligned} \sum_{j=0}^{m}\binom{m+1}{j}B_j&=0,(m>0)\\ B_0&=1 \end{aligned}j=0∑m​(jm+1​)Bj​B0​​=0,(m>0)=1​

利用归纳法证明​

这个证明方法来自 Concrete Mathematics 6.5 BERNOULLI NUMBER。

运用二项式系数的恒等变换和归纳法进行证明：

Sm+1(n)+nm+1=∑k=0n−1(k+1)m+1=∑k=0n−1∑j=0m+1(m+1j)kj=∑j=0m+1(m+1j)Sj(n)\begin{aligned} S_{m+1}(n)+n^{m+1}&= \sum_{k=0}^{n-1}(k+1)^{m+1}\\ &=\sum_{k=0}^{n-1}\sum_{j=0}^{m+1}\binom{m+1}{j}k^j\\ &=\sum_{j=0}^{m+1}\binom{m+1}{j}S_j(n) \end{aligned}Sm+1​(n)+nm+1​=k=0∑n−1​(k+1)m+1=k=0∑n−1​j=0∑m+1​(jm+1​)kj=j=0∑m+1​(jm+1​)Sj​(n)​

令 S^m(n)=1m+1∑k=0m(m+1k)Bknm+1−k\hat{S}_{m}(n)=\frac{1}{m+1} \sum_{k=0}^{m} \binom{m+1}{k}B_kn^{m+1-k}S^m​(n)=m+11​∑k=0m​(km+1​)Bk​nm+1−k，我们希望证明 Sm(n)=S^m(n)S_m(n)=\hat{S}_m(n)Sm​(n)=S^m​(n)，假设对 j∈[0,m)j\in[0,m)j∈[0,m)，有 Sj(n)=S^j(n)S_j(n)=\hat{S}_j(n)Sj​(n)=S^j​(n)。

参考实现
using ll = long long;
constexpr int MAXN = 10000;
constexpr int mod = 1e9 + 7;
ll B[MAXN];        // 伯努利数
ll C[MAXN][MAXN];  // 组合数
ll inv[MAXN];      // 逆元（计算伯努利数）

void init() {
  // 预处理组合数
  for (int i = 0; i < MAXN; i++) {
    C[i][0] = C[i][i] = 1;
    for (int k = 1; k < i; k++) {
      C[i][k] = (C[i - 1][k] % mod + C[i - 1][k - 1] % mod) % mod;
    }
  }
  // 预处理逆元
  inv[1] = 1;
  for (int i = 2; i < MAXN; i++) {
    inv[i] = (mod - mod / i) * inv[mod % i] % mod;
  }
  // 预处理伯努利数
  B[0] = 1;
  for (int i = 1; i < MAXN; i++) {
    ll ans = 0;
    if (i == MAXN - 1) break;
    for (int k = 0; k < i; k++) {
      ans += C[i + 1][k] * B[k];
      ans %= mod;
    }
    ans = (ans * (-inv[i + 1]) % mod + mod) % mod;
    B[i] = ans;
  }
}
